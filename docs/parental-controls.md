# Parental Controls & Multi-Profile Management

HomeStream provides multi-profile isolation and age-appropriate content gating.

---

## 🛡️ Rating Tiers

Profiles can be configured with content rating ceilings:

- **U**: Universal (Early childhood, general audience)
- **PG**: Parental Guidance (Mild content)
- **12**: Ages 12 and above
- **15**: Ages 15 and above
- **18 / Adult**: Full access without restrictions

When a profile is set to a restricted tier:
1. Adult library titles exceeding the rating ceiling are hidden from feeds, search, and catalogs.
2. In-progress video streaming requests evaluate rating policies before serving video segments.
3. Kids mode hides YouTube and administrative settings.

---

## 🔒 Parent PIN Protection

- Switching from a Kids profile to an Adult profile requires the 4–8 digit Parent PIN.
- Prevents unauthorized access on shared household smart TVs and living room Chromecasts.
- PIN can be set and updated directly in the Profile Management screen.
